A one-page cheat sheet. Everything this config adds lives under the =C-c p=
("Productivity") prefix and is mirrored in the *Productivity* menu; the F-keys
are kept for muscle memory. Pause after =C-c p= and =which-key= will list every
option.

* Plan & review
| Key              | Command                    | Action                    |
|------------------+----------------------------+---------------------------|
| =C-c p a=        | =ps/show-agenda=           | open the agenda           |
| =C-c p c c=      | =ps/show-calendar=         | open the Calendar (day)   |
| =C-c p c d=      | =ps/show-calendar-day=     | Calendar at a day         |
| =C-c p c w=      | =ps/show-calendar-week=    | Calendar at a week        |
| =C-c p c m=      | =ps/show-calendar-month=   | Calendar at a month       |
| =C-c p c y=      | =ps/show-calendar-year=    | Calendar at a year        |
| =C-c p A=        | =org-agenda=               | full agenda dispatcher    |
| =C-c p n= / =F9= | =ps/show-tasks=            | open the Tasks view       |
| =C-c p S= /key/  | =ps/show-situation=        | open a situation          |
| =C-c p S ?=      | =ps/situations-switch=     | pick a situation by name  |
| =C-c p v=        | =ps/org-show-availability= | availability (free slots) |
| =C-c p x=        | =ps/show-conflicts=        | conflict check            |

The key after =C-c p S= is the situation's own =:key= — the set is yours, so see
[[file:Situations.org][Situations]] and your =workspace.org= for which letters are live.

* Files & navigation
| Key           | Command                             | Action                             |
|---------------+-------------------------------------+------------------------------------|
| =F8=          | =ps/file-tree-toggle=               | show / hide the file tree          |
| =C-c p F=     | =ps/file-tree-cycle-file-set=       | cycle the file set                 |
| =C-c p g=     | =ps/file-tree-toggle-agenda-filter= | file set also restricts the agenda |
| =C-c p f=     | =recentf-open-files=                | open a recent file                 |
| =C-c p i=     | =imenu=                             | jump to a heading by name          |
| =s-r=         | =counsel-projectile-rg=             | search the whole project           |
| =C-c <left>=  | =ps/nav-back=                       | back to the previous place         |
| =C-c <right>= | =ps/nav-forward=                    | forward again                      |
| =C-c p 1=     | =delete-other-windows=              | keep only the current window       |

=C-c p |= (also =C-x |=, =ps/window-split-toggle=) flips a split between
horizontal and vertical.

In a folder listing, =^= goes up to the parent (so does clicking =..=), and =(=
shows the full =ls= details. In a Markdown file, =C-c |= stops lines wrapping,
for a table too wide to fit. In a rendered web page, =R= shows just the article
and =&= reopens it in your real browser. See [[file:Files-and-navigation.org][Files & navigation]].

* Info triage
Only useful with the optional capture inbox — see [[file:Info-triage.org][Info triage]].

| Key       | Command               | Action                 |
|-----------+-----------------------+------------------------|
| =C-c p I= | =ps/info-triage-open= | open the capture queue |

Inside the queue itself, single keys: =RET= follow, =n= / =p= next / previous
item, =d= drop the item at point, =s= sync, =g= rebuild the list, =e= open the
folder outside Emacs, =b= / =f= back / forward, =q= put it away.

* Org task editing (in an Org file)
| Key             | Action                                    |
|-----------------+-------------------------------------------|
| =C-c C-t=       | change TODO state                         |
| =S-→= / =S-←=   | cycle TODO state                          |
| =C-c ,=         | set priority                              |
| =C-c C-s=       | set SCHEDULED date                        |
| =C-c C-d=       | set DEADLINE date                         |
| =M-RET=         | new task at the same level                |
| =M-→= / =M-←=   | demote / promote heading                  |
| =M-↑= / =M-↓=   | move subtree up / down                    |
| =TAB= / =S-TAB= | fold subtree / cycle whole-buffer folding |
| =C-x C-;=       | comment / uncomment the selected lines    |

Inside a =#+begin_src= block, =C-x C-;= uses the block language's own comment
syntax, so uncommenting example code removes the prefix rather than adding
another one.

For general Emacs keys (movement, files, windows), see [[file:Emacs-basics.org][Emacs basics]].
