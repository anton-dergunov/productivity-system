* What it is
A minimalist Emacs configuration for planning your work and life in plain-text
[[https://orgmode.org/][Org Mode]] files, with a clean, visual *agenda* at its centre. The workflow is
inspired by /Getting Things Done/: capture things out of your head, keep them in
a handful of Org files, and review a single agenda that surfaces what matters
today.

The guiding ideas:

- *Plain text, forever.* Your data is Org files you own — no database, no lock-in.
- *Calm and visual.* A readable agenda with pills, icons, and a real timeline,
  rather than a wall of text.
- *Org-native.* It builds on Org and a few well-chosen packages instead of
  reinventing them.
- *Minimal and yours.* Sensible defaults, with one obvious place to change each
  setting (see [[file:Customization.org][Customization & appearance]]).

* Built on
This configuration stands on excellent free software. The main pieces:

- *Org Mode* — the foundation: outlines, tasks, the agenda, capture, dates.
- *org-super-agenda* — groups the agenda into the /Schedule/, /Due/,
  /High-priority/, /In progress/, /Next up/ … sections.
- *org-modern* — the modern look: timestamp pills, priority and TODO badges.
- *org-superstar* — nicer heading bullets.
- *org-appear* — shows a link's or emphasis's raw markup only while the cursor
  is on it.
- *org-journal* — dated journal entries.
- *treemacs* — the file-tree sidebar.
- *markdown-mode* — reading and following links in Markdown notes.
- *visual-fill-column* — the centred reading width for plan files.
- *valign* — keeps tables aligned in the documentation's reading view.
- *ultra-scroll* — smooth, pixel-precise scrolling.
- *claude-code-ide* and *eat* — the AI assistant's side panel and the terminal
  it runs in.
- *ivy* / *counsel* / *counsel-projectile* / *ivy-rich* / *swiper* — the
  completion and search stack.
- *projectile* — project-aware navigation and search.
- *magit* — the Git interface (behind the automatic sync).
- *jinx* — the quiet, multilingual typo checker.
- *guess-language* — helps the spell checker pick the right language.
- *helpful* — richer help buffers.
- *which-key* — the popup that lists what a key prefix can do.
- A range of *color-theme* packages — Solarized, ef-themes, Doom, Catppuccin,
  Tokyo Night, Gruvbox, Nord, and more (see [[file:Customization.org][Customization & appearance]]).

On top of these sit this project's own modules (the =ps/...= features:
the agenda layout, schedule view, availability, conflicts, file tree, git sync,
and so on) — see [[file:Developing.org][Developing & extending]].

* Requirements
- *Emacs 29 or newer*; on macOS, the patched build described in
  [[file:Installation.org][Installation]].
- Optional: the *Material Symbols Outlined* font (for category icons) and the
  *enchant* library plus dictionaries (for typo checking). Both are covered in
  [[file:Installation.org][Installation]]; everything still loads without them.

* Version
There is no formal release number yet — the configuration is versioned by its

* History
It started in 2021 as a personal Emacs setup and grew, mostly during 2026, into
a planning system of its own. The main steps:

- *2021–2024 — a personal configuration.* A plain Emacs setup, rewritten in 2024
  as one readable configuration file, with the first category icons in the
  agenda and a first fix for the blank lines mobile Org apps remove.
- *Spring 2026 — building blocks.* Free-time availability, conflict checking and
  timezone shifting became built-in commands. Every setting moved to one place,
  and the Productivity menu appeared. Notes began syncing to Git automatically.
- *June 2026 — the look.* A new file tree with category icons. The agenda was
  redesigned into aligned columns with badges, a timeline for the day, and a
  calendar for any span. A quiet multilingual typo checker, a planning-focused
  mode line, an auto-hiding scroll indicator, and this documentation arrived,
  along with the AI assistant in a side panel.
- *July–August 2026 — reliability and reach.* A fix for Emacs freezing on macOS.
  Blank lines lost to mobile edits recovered from your notes' own history.
  Dropbox and Git made safe together, and automatic saves that never write over
  a newer file. Situation views, fonts chosen by role with a comfortable reading
  width, several notes folders switchable without restarting, links that open
  on one click, and back and forward.
- *September 2026 — the reasoning written down.* Why each part works the way it
  does is now recorded for anyone changing the code.

The longer story, including which approaches were tried and replaced and why, is
in [[file:../design/history.md][the design history]].
